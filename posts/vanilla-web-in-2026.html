Vanilla web in 2026

2026-07-25 · Saad

The browser platform is bigger than it was five years ago. CSS grid, container queries, view transitions, native modules, custom properties, the Gamepad API — most of what I used to reach for a library for is now one file away.

What you get for free

  • Custom properties + data-theme is a full theme system.
  • <canvas> and requestAnimationFrame is a whole animation runtime.
  • navigator.getGamepads() gives you controller input in ten lines.
  • localStorage is a settings store.

What it costs

You write your own components. That's the whole trade. If your site is five pages, that's a good trade. If it's five hundred, use a framework — I'm not a purist.

This site is proof for me that it's still fun. No node_modules. No dev server. Open index.html, refresh.

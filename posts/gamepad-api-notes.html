Notes on the Gamepad API

2026-07-28 · Saad

The Gamepad API is one of those web APIs that is small, old, and just works. Plug in a controller, press a button, listen for gamepadconnected. That's the whole handshake.

The polling loop

There are no events for buttons — you poll. Once per animation frame: 

function poll() {
  for (const gp of navigator.getGamepads()) {
    if (!gp) continue;
    if (gp.buttons[0].pressed) console.log("A");
  }
  requestAnimationFrame(poll);
}
requestAnimationFrame(poll);

Standard mapping

Most modern controllers (Xbox One/Series, DualShock 4/5, 8BitDo Pro) report as mapping: "standard", so you can hard-code button indices: 0=A/✕, 1=B/○, 4=LB/L1, 5=RB/R1, 9=Start.

Edge detection + repeat

For menu navigation you want key-repeat semantics — press once triggers immediately, hold triggers after a short delay. The trick is to remember which buttons were already pressed on the previous frame and only dispatch on the transition. See js/controller.js in this repo for how I wired it.

The nicest thing you can do for a controller user is make sure the UI never eats their inputs.
